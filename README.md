# remark-plugins
A collection of remarkjs plugins for embedding interactive and structured content in Markdown, built on top of [ZikoJS](https://github.com/zikojs/ziko).

## Plugins

|Plugin|Description|
|-|-|
|remark-mindx-elixir|Embed interactive MindElixir mind maps in Markdown.|

> More plugins are planned for diagrams, visualizations, 3D scenes, and other interactive content.
